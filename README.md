# Campus Event Registration Desk

Browser-based event registration desk built with HTML5, CSS3 and JavaScript (no build step, no dependencies).

## Files
- `index.html` - page structure
- `style.css` - styling and animations
- `script.js` - data, validation, registration, display, search/filter, localStorage, cancellation
- `images/` - coordinator photos

## Run locally
Open `index.html` in a browser.

## Deploy on Vercel
Import this repo in Vercel, keep Framework Preset as "Other", leave build and output settings empty, and deploy.
